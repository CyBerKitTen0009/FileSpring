# 兼容性矩阵

| 项目 | 当前状态 |
| --- | --- |
| macOS Apple Silicon / 当前本地卷 | 本地编译、自动化核心测试、原生 GUI 复制与撤销已验证；磁盘格式未独立核实 |
| macOS Intel | 未验证，配置 CI 原生测试 |
| Windows 10/11 x86-64 | 未验证，配置 CI，需实际 NTFS/锁/权限/长路径/重解析点测试 |
| Linux x86-64 | 未验证，配置 CI，需实际 ext4/Btrfs 测试 |
| Windows/Linux ARM64 | 未验证 |
| WSL CLI | 架构可独立构建，未验证 |
| 第二真实卷上的移动 | 协议已实现，未实测 |
| FAT32/exFAT | 当前发布机制不支持，失败时不覆盖现有目标 |
| SMB/NAS/断连 | 未验证，不作为当前支持能力 |
| 符号链接/Windows Junction | 默认拒绝跟随和修改；macOS 符号链接测试已通过，Windows 未实测 |
| 中文、空格、shell 特殊字符 | 隔离目录核心操作已测试 |
| 非 Unicode 名称 | 浏览时显示替代字符；操作日志 v1 拒绝写操作。Linux 测试待 CI |
| 长文件名 | 120 个 ASCII 字符加中文/特殊字符已测试；平台最大长路径未验证 |
| ACL/扩展属性/资源叉/稀疏/硬链接拓扑 | 尚未完整保留 |
| 双核/4 GB/机械硬盘 | 未验证 |

CI 文件只是测试方案，尚无远端仓库、没有运行过跨平台 CI，不将配置视为测试通过。
